# Bat Swing Game

A first-person dungeon crawler where you bonk bats with a baseball bat.

![Gameplay Screenshot](Screenshots/Screenshot%20from%202025-12-07%2017-03-27.png)

## About

This is a first-person shooter submitted for the [7DFPS 2025 Game Jam](https://itch.io/jam/7dfps) (December 5-14, 2025).

## Concept

Navigate through a never-ending dungeon, bonking flying bats with your trusty baseball bat. Battle through waves of bats as you crawl deeper into the dungeon, seeing how far you can make it in this endless descent.

## Engine

This game is built using **Quarkit Engine**, an independent hard fork of Godot Engine maintained by the developer. Quarkit Engine maintains compatibility with Godot 4.x while incorporating custom modifications and optimizations tailored for specific development workflows.

## Game Jam

- Event: 7DFPS 2025
- Duration: December 5-14, 2025
- Challenge: Create a first-person game in seven days
